# Real-life Use Cases

# 1. Gmail
# a. Auto completion
When you are typing any sentece in your gmail you will notice that it tries to auto complete. This auto completion is done using nlp.

# b. Spam filters
If these emails didn't have spam filters then you will be so much worried and you will get so much heeadache by this bombarding of all kind of commercial spam but luckily using nlp you can filter them and take them out of your inbox. 
NLP uses keywords the spam emails will have like **"Hurry up the offer ends!!"**, **"You won some Prize"** and all of that bull shit. So, based on some of those term and ML classification model, you can filter the spam messages.

# 2. Language Translation
You can use Google Translate and you can pretty much translate a sentence in one language to another language, with very high accuracy. This wasnt possible many years back but nowadays these translator are pretty good.

# 3. Customer Service Chatbot
If you are using any service, let's say bank and you go to chat service, type in a message and many times there is no human on the other hand. The chatbot can interpret your language and it can derive intent out of it and it can respond to your question on its own.

# 4. Voice Assistants
Voice Assistants such as **Amazon, Alexa and Google Assistant.** They can even tell you that **"You have meeting at 9 o'clock and there is a lot of traffic so instead of leaving at 8:30 you should leave at 8:15.** It can do that kind of assistance.

# 5. Google Search
Google Search uses NLP to answer your questions and they use this special language model called **BERT**.  
So before BERT if you type a question in google saying can you get medicine for someone pharmacy. Before that it wasn't giving you the right answer but now it gives you a precise answer and this is again possible bacause of NLP.

# 6. Automated New Generation
In news companies like Bloomberg automate the news stories to predict the market events.
All the new stories are not written by some human editor basically. They are all generated by computer using NLP, some AI techniques, they detect some technical signals and they can auto write these stories and that' pretty cool.

# What is NLP?
NLP standa for Natural Language Processing.
NLP is a field of computer science and AI that give machines an ability to understand human language better and to assist in language related task.

If you look at computer traditionally, they are designed to work on number ad they were pretty good at task which are related to numbers, but now using NLP you can have computer that assist language related tasks, the use cases that we saw like question & answer, language translation like that.
